# Configuration examples

`approval-template.json` starts empty: approve your exact candidate after the full native runtime matrix. `tested-device-approval.json` records the historic tested package fingerprints; it is evidence, not a downloadable binary or cross-device hardware certification.

`policies.json` enables only the two MediaCodec defaults. `policies-with-extensions.json` also requests official signed Bitwarden and uBlock Origin packages. Merge desired fields into an existing policy instead of overwriting unrelated settings. No browser profile, extension storage or vault is included.
